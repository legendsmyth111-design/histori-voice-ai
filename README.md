# HistoryVoice AI — Smart Research & History Assistant

## Overview
HistoryVoice AI is a multi-page interactive web application designed for history students, researchers, and general users to search, explore, read, and listen to historical research and literature.

## Live Deployed URL
🔗 **Live App:** https://history-voice-ai.vercel.app

## Key Features
* ⚡ **100% Incognito & Direct Access:** No authentication/login required.
* 🤖 **AI History Assistant:** Interactive research chatbot powered by Gemini 2.5 Flash.
* 🧭 **Explore Topics:** Pre-configured historical research categories.
* 📚 **Book Library:** Authentic book literature index.
* 🔊 **Voice Reader:** Built-in web speech TTS tool for historical excerpts.

## Tech Stack
* Next.js 14 (App Router)
* Tailwind CSS
* Google Gemini AI API (`@google/genai`)
* Deployed on Vercel
